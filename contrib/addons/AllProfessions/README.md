# All Professions

Cataclysm 4.3.4 addon that provides a single window for the eleven primary professions.
Known professions are shown at full opacity and unknown professions are dimmed.

The Cataclysm client only exposes the first two primary profession spells to its UI. Addons cannot
open additional profession windows because the only available client API requires casting that spell.

## Install

Copy `AllProfessions` to the client's addon directory:

```text
World of Warcraft/Interface/AddOns/AllProfessions
```

Enable the addon at character selection. Open it using the minimap button or either command:

```text
/professions
/allprofessions
```
